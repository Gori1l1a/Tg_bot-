# 🤖 Семейный Помощник (Family Assistant Bot)

Telegram-бот на Python, созданный для помощи родителям и близким. Он присылает прогноз погоды, напоминает о важных делах и помогает не забывать о мелочах.

## ✨ Возможности

- 🌤 **Погода по утрам:** Каждый день в 8:00 бот присылает актуальный прогноз погоды (используется бесплатный API Open-Meteo).
- 🔔 **Случайные напоминания:** Каждый вечер в 20:00 бот присылает полезное напоминание (попить воды, проверить утюг и т.д.).
- ⏰ **Свои напоминания:** Команда `/set_remind` позволяет создать напоминание на конкретное время (например, в 19:30) или через определенное количество минут.
- 🌤 **Погода по запросу:** Команда `/weather` покажет погоду прямо сейчас.
- 🔔 **Напоминание по запросу:** Команда `/remind` выдаст случайное напоминание.
